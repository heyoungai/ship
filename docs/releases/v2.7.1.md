# ship v2.7.1

**2026-07-24**

## Highlights

- **Hotfix**：修复 `deploy.compose.pin = "digest"` 在 buildx multi-arch / 网络抖动下记错、比错镜像身份，导致 deploy 误失败的问题。

## Fixed

- Pin 身份统一走 `docker buildx imagetools inspect` 的可钉扎 `sha256:...`，禁止静默回退本地 config digest。
- 拿不到有效 pin 或 compose 未使用 `@digest` 时降级 `pin=tag` 并警告，避免硬失败。
- `DigestsMatch` 支持 pin ∈ index 成员等兼容比较。

## Upgrade notes

- 用 v2.7.0 发布且 manifest 可能已记错 digest 的版本：升级后重新 `ship push`，或临时 `pin = "tag"`。
- 生产 compose 应用 `@${APP_IMAGE_DIGEST}`（或等价），否则请显式 `pin = "tag"`。
